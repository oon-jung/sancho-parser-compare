## 2. 논문 12편을 구하는 법

PDF는 넣지 않았다. 저작권 때문이며, `papers.csv`의 DOI로 각자 받으면 된다.

1. `papers.csv`를 연다.
2. `DOI` 칸의 값을 `https://doi.org/` 뒤에 붙여 주소창에 넣는다.
   예) `10.3390/nu12040956` → `https://doi.org/10.3390/nu12040956`
3. 기관 계정으로 로그인해 PDF를 받는다.
4. 받은 파일이 같은 판본인지 확인한다. 터미널에서

   ```
   shasum -a 256 받은파일.pdf
   ```

   결과 앞 16자리가 `papers.csv`의 `sha256` 칸과 같으면 같은 판본이다.

`kohanja_02` 한 편만 DOI가 없다. 이 논문은 따로 받아야 한다.

언어 구성은 한국어 3편, 영어 3편, 중국어 3편, 일본어 1편, 한자 혼용 2편이고 모두 128쪽이다.

## 3. 파싱 — `parsed/`를 쓸지, 직접 할지

**결론: `parsed/`를 그대로 쓰는 것을 권한다.**

파싱은 무작위가 아니라서 같은 도구 같은 버전이면 결과가 같다. 그런데 버전이 조금만
달라도 항목의 개수와 경계가 바뀌고, 그러면 조각 번호가 어긋나 서로 결과를 비교할 수
없게 된다. 이 자료는 다음 버전에서 만들었다.

| 꾸러미 | 버전 |
|---|---|
| docling | 2.118.1 |
| docling-core | 2.92.0 |
| docling-parse | 7.15.0 |
| pymupdf | 1.28.2 |

### `parsed/` 파일의 생김새

문서마다 JSON 하나다. `parsed/ko_01.json`을 열면 이렇다.

```json
{
  "doc_id": "ko_01",
  "kind": "born_digital",
  "lang": "ko",
  "pages": 10,
  "docling": [
    { "i": 0, "label": "picture",        "page": 1, "bbox": [...], "text": "" },
    { "i": 1, "label": "section_header", "page": 1, "bbox": [...], "text": "국내산 초피와 …" },
    { "i": 2, "label": "text",           "page": 1, "bbox": [...], "text": "현대사회는 …" }
  ]
}
```

- `docling`은 읽기 순서대로 늘어놓은 항목 목록이다.
- `label`은 `section_header`(제목) · `text`(본문) · `list_item`(목록) · `table`(표) ·
  `picture`(그림) · `caption`(캡션)이다.
- 표는 `html` 칸에 표 구조가 들어 있다.
- 그림은 `text`가 비어 있다. docling은 그림의 위치만 주고 내용을 읽지 못한다.
- **제목의 등급은 없다.** 대제목과 소제목이 모두 `section_header`로 온다.

### 직접 파싱하려면

```python
from docling.document_converter import DocumentConverter
doc = DocumentConverter().convert("논문.pdf").document
```

OCR은 껐다. 켜면 스캔본에서 글자가 나오지만 이 실험과 조건이 달라진다.

## 4. 그림 서술 — `figure_descriptions.json`

docling은 그림 내용을 비운다. 그래서 그림 영역을 잘라 로컬 모델에 넣고 글로 받아
그 자리에 채웠다. 이 글이 조각에 들어가고, 그림 12문항이 여기에 걸려 있다.

```json
[
  { "doc_id": "ko_01", "figure_item": "42", "page": 3,
    "crop": "ko_01_fig01_p3.png",
    "caption": "Fig. 1. DPPH radical scavenging activity …",
    "description": "막대 그래프로, DPPH 라디칼 소거 활성(%)을 나타내며 …" }
]
```

`figure_item`은 `parsed/`의 항목 번호 `i`와 같다. 이 번호로 파싱 결과와 이어 붙이면 된다.

**같은 모델이라도 장비가 다르면 글이 달라질 수 있다.** 같은 기계에서 두 번 돌려 글자까지
같은 것은 확인했지만, 다른 GPU나 다른 양자화로 돌리면 문장이 달라진다. 그림 문항 채점이
이 글에 걸려 있으므로 **이 파일을 그대로 쓰기를 권한다.**

직접 만들려면 Ollama에 `qwen3-vl:32b-instruct`를 받고 `temperature 0`, `num_ctx 8192`로
돌린다. 기본 태그(`qwen3-vl:32b`)는 생각 모드라 내용이 비어 나오므로 `-instruct`를 써야 한다.

## 5. 채택한 자르는 방식

| 항목 | 값 |
|---|---|
| 자르는 자리 | docling이 잡은 절 경계 |
| 목표 크기 | 900토큰 |
| 최대 | 7,000토큰 |
| 최소 | 120토큰 |
| 겹침 | 없음 (한 문단이 최대를 넘을 때만 100토큰) |
| 절 이름 태그 | **붙이지 않는다** |
| 표 | 통째로 한 조각. 캡션을 맨 앞에 붙임 |
| 그림 | 서술을 `[그림 서술] …`로 본문 자리에 넣고 자름 |
| 토큰 세는 법 | cl100k |

**주의.** 지금 `chunk_policy.py`는 조각 맨 앞에 `## 제목`을 항상 붙인다. 채택한 방식은
붙이지 않는 것이다. 그대로 쓰면 다른 방식이 되므로 그 줄을 빼야 한다.

```python
# chunk_policy.py 176줄 — 지금
return f"## {heading}\n{text}" if heading else text
# 채택한 방식
return text
```

### `chunks/` 파일의 생김새

`chunks/chosen_SEC_none.jsonl`은 한 줄에 조각 하나다.

```json
{ "chunk_id": "ko_01:SEC_none:0003", "doc_id": "ko_01",
  "text": "현대사회는 급속한 경제성장에 의한 …",
  "kind": "body", "tokens": 800, "pages": [1,2],
  "section": "서 론", "sec": 3, "items": [12,13,14], "fig_items": [] }
```

- `kind`는 `body`(본문) · `table`(표) · `reference`(참고문헌)이다.
- `items`는 이 조각에 들어간 파싱 항목 번호다.
- `fig_items`는 이 조각에 들어간 그림의 항목 번호다. 그림 문항 채점에 쓴다.
- `chosen_SEC_none.csv`는 같은 내용을 엑셀에서 볼 수 있게 만든 것이다.

문서별 조각 수는 en_01 98 · en_02 106 · en_03 109 · ja_01 37 · ko_01 96 · ko_02 73 ·
ko_03 5 · kohanja_01 56 · kohanja_02 125 · zh_01 51 · zh_02 50 · zh_03 56이다.
직접 자른 결과가 이 숫자와 다르면 어딘가 설정이 다른 것이다.

## 6. 채점하는 법

### 6-1. 골드 45문항 — 검색이 정답 조각을 찾았는가

정답 칸의 글자가 조각 안에 통째로 들어 있으면 적중이다. 비교하기 전에 양쪽을 똑같이
다듬는다. 공백·따옴표·붙임표를 지우고 유니코드를 정규화한 뒤 소문자로 바꾼다.

```python
import re, unicodedata
KEEP = re.compile(r"[\s'\"‘’“”\-–—‐‑]+")
def norm(t):
    return KEEP.sub('', unicodedata.normalize('NFKC', t)).lower()

hit = norm(질문의_정답) in norm(조각의_글)
```

질문과 조각을 같은 임베딩 모델로 벡터로 바꾸고 코사인 유사도로 전체 조각을 줄 세운다.
정답이 든 조각이 몇 번째에 오는지가 그 문항의 순위다. 이 실험은 BGE-M3를 썼고
문서를 미리 고르지 않고 12편을 한 풀로 두었다.

### 6-2. 그림 12문항 — 그림 서술이 든 조각이 올라왔는가

서술 내용이 맞는지는 채점하지 않는다. 서술을 만든 모델과 채점하는 모델이 같아지는
순환을 피하기 위해서다.

```python
hit = (조각['doc_id'] == 문항['doc_id']) and (문항['figure_item'] in 조각['fig_items'])
```

### 6-3. 답변 정확도 — 그 조각으로 만든 답이 맞는가

닮은 순서대로 조각을 담되 합계 **6,000토큰**까지만 담아 답변 모델에 준다. 논문 지면으로
약 3쪽이다. 이 실험은 gpt-4.1-mini를 썼다.

답변 프롬프트

```
아래 발췌만 근거로 질문에 한국어로 답하라. 두 문장 이내.
발췌에 근거가 없으면 정확히 '근거 없음'이라고만 답하라.
추측하거나 발췌 밖 지식을 쓰지 마라.

[발췌]
{조각들을 --- 로 이어 붙임}

[질문]
{질문}
```

채점 프롬프트

```
질문과 정답, 그리고 응답이 주어진다. 응답이 정답을 담고 있는지 판정하라.
정답: 정답의 핵심 값·내용을 맞혔다(표현이 달라도 됨).
부분: 일부만 맞거나 범위가 어긋난다.
오답: 틀렸거나 '근거 없음'이다.
정답/부분/오답 중 한 단어만 출력하라.
```

**이 채점은 답변 모델과 같은 모델이 한다.** 자기 답에 관대할 수 있어 사람 검수가 남아 있다.
표본을 읽어 보니 다시 봐야 할 문항이 최소 3개, 경계 사례까지 5개였다.

## 8. 지난 실험에서 나온 기준값

같은 문항으로 잰 결과다. 새로 만든 방식이 이보다 나은지 견주면 된다.

| 방식 | 같은 분량 답변 정답 | 정답 조각 6등 안 |
|---|---:|---:|
| 고정 5,000자/250자 | 23 / 57 | 33 / 45 |
| **절 단위 청킹 (채택)** | **50 / 57** | 31 / 45 |
| 절 단위 + 절 이름 태그 | 46 / 57 | 27 / 45 |
| 절 단위 · 목표 600토큰 | 47 / 57 | 31 / 45 |

"같은 분량"은 6,000토큰까지 담아 답변 모델에 준 경우다. "6등 안"은 닮은 순서로 줄 세웠을
때 정답이 든 조각이 상위 6개에 들어온 문항 수다.
