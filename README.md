# 산초 파서 비교

PDF 파서 파일럿의 실험 결과를 정적 페이지로 정리한 사이트입니다.

- ① 파서 3종 비교 (parsers.html) — pymupdf · docling · MinerU 지면 겹쳐 보기, VLM 대 PyMuPDF4LLM
- ② 청킹 (chunking.html) — 절 단위 · 고정 1000/100 · 고정 5000/250
- ③ 표 정확도 (tables.html) — 사람 전사 골드 대조
- ④ 파서 선택 (parserchoice.html) — docling 기준 + 예외 라우팅
- ⑤ 완주 실험 (e2e.html) — 논문→답변, 언어 조건 4개
- ⑥ 청킹 방식 비교 — 아래 여섯 페이지

## ⑥ 청킹 방식 비교

논문 12편을 같은 방식으로 파싱해 두고 자르는 규칙만 바꿔 검색과 답변 정확도를 쟀습니다.

- 결과 (exp23.html) — 논문을 어떻게 잘라야 가장 잘 찾는가. 네 가지 방식을 57문항으로 비교하고, 문항마다 실제 답변을 대조할 수 있다
- 방법 (exp23how.html) — 파이프라인 8단계와 절 이름 줄이 조각의 글을 바꾸는 방식
- 언어별 요약 (exp1summary.html) — 네 언어에서 절이 청크로 얼마나 온전히 남는가
- 지면과 파싱 결과 (exp1.html) — 파싱 항목을 논문 지면 위에 올려 보기, 그림 서술 모델 비교
- 청크 경계 보기 (exp1chunk.html) — 고정 5,000자와 절 단위가 같은 지면을 어떻게 자르는가
- 그림에서만 답이 나오는 문항 (figq.html) — 12문항과 그 근거 그림

각 페이지 오른쪽 아래에서 본문 너비를 고르고, "본문 고치기"를 누르면 제목·위쪽 메뉴 이름·탭 제목·설명·표 칸까지 직접 고칠 수 있습니다. 고친 내용은 그 브라우저에만 남습니다. 원본 파일과 이 사이트는 바뀌지 않습니다. 반영하려면 "고친 글 복사"나 "내려받기"로 꺼내어 파일에 옮겨야 합니다.
